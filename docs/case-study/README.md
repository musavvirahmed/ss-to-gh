# Case-study

This folder holds any and all assets for a case study write-up about this repo. The full write-up lives in the [root README.md](../../README.md) file.

## Add an image

1. Put the image file inside this folder.
2. Link it from the root README with a relative path, for example '![Alt text about your image](docs/case-study/your-image.png)'.
3. Keep both the file names and the alt text short and descriptive.
